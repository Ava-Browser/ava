# Security

Ava is in early development. There are no supported stable releases or security
update guarantees yet. Do not rely on it for sensitive browsing.

## Reporting a vulnerability

Do not publish vulnerabilities, exploit code, credentials, or private browsing data
in a public issue or pull request.

Use this repository's **Security → Report a vulnerability** option when available.
If it is not available, open an issue requesting a private security contact **without
including vulnerability details**, and wait for a maintainer to provide one.

A private report should include the app commit, engine commit, macOS version,
reproduction steps, and likely impact. Remove unrelated personal data.

For vulnerabilities confined to Ladybird itself, follow the
[upstream security policy](https://github.com/LadybirdBrowser/ladybird/security/policy).

## Maintainer setup

Before public launch, enable private vulnerability reporting in the repository's
security settings and confirm that maintainers receive notifications.
